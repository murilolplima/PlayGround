## Play

A small browser-based 3D horror game. Serve this folder over HTTP, then open it in a modern browser:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`. Find the five glowing sahur bundles, avoid the creature, and reach the red exit door.

- **Desktop:** WASD to move, mouse to look, Shift to run, Esc to release the mouse.
- **Touchscreens:** Use the on-screen direction pad and drag the scene to look around.
